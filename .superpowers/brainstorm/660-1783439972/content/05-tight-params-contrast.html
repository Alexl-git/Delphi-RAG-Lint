Contrast guard — EnsureReadable(FG, BG, 4.5)

function Foo
FG #0b57d0 on dark BG
ratio 2.1 — FAILS 4.5
→
function Foo
auto-lightened to #569cd6
ratio 6.4 — PASSES
The renderer computes each syntax color’s WCAG ratio against the live popup background (after the IDE theme is applied). Anything under the threshold is nudged in lightness until it passes — so text is never invisible, whatever theme or palette is active. Pure arithmetic, no dependency, trivially unit-testable (known pairs → known ratios).
