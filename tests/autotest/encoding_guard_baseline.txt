# strict CRLF / 7-bit ASCII / no BOM. 80 files under src\ and tests\ predate that
# rule being enforced by anything. Rewriting all 80 would be a large, untestable
# change to linter and preprocessor FIXTURES whose byte content some runners pin,
# for no behavioural gain -- dcc reads both. So they are recorded here and exempted
# from the lone-LF check ONLY. The ASCII and BOM checks still apply to them.
#
# WHAT THE GUARD ACTUALLY PROTECTS (register HAZARD H1): a file that is CRLF today
# must not silently become LF. T3j's implementer converted two .pas files to LF with
# a scripted edit and the content diff, the build, and a 185/187 green battery ALL
# missed it -- git normalizes on commit, so the committed blob was correct while the
# on-disk file dcc64 reads was wrong. Anything NOT listed here must have zero lone LFs.
#
# TO REMOVE AN ENTRY: convert the file to CRLF, delete its line, re-run the guard.
# TO ADD ONE: don't. A new entry means a file just got damaged -- fix the file.
#

# class MIXED = part CRLF, part LF. Those three are the H1 shape already realised,
# pre-existing in the IDE plugin tree; recorded rather than silently lumped in with
