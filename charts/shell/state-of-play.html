Two corrections to the catalogue, both found by checking population. tested-by was listed ship-now because covered_by exists in the schema — it holds zero rows in every index, so it is not shippable and has been demoted. And touches-tables is SERVER-only by design: the client has no FireDAC connection at all, which is why its sql_reads and sql_writes are 0/0. That is correct behaviour, not a gap, and the command must say so rather than render an empty chart.

effects deferred, deliberately. effect_summary is the richest fact available (7,254 rows on CLIENT, 5,284 on SERVER) and was my first pick — but its values are coded letters like g,s,? whose legend I have not found. Decoding that is a research task, not an implementation task, and it is the wrong thing to hand an unattended session. It moves to the front of the queue once someone reads the encoder.

Together with the two already live, that spans four tiers: code (butterfly, who-calls), structure (deps), UI (event-wiring) and database (touches-tables) — which is exactly the span the blocked protocol-trace will need once the engine team lands the enum binding.
