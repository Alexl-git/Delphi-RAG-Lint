# drag-lint

This page documents the "View > Tool Windows > drag-lint" menu entry -- the main drag-lint dockable tool window.

Read this to find the main drag-lint dockable panel. It opens from View > Tool Windows > drag-lint, and is the same panel as the one reached through the drag-lint menu.

## Where to click

* Tool window: **View > Tool Windows > drag-lint**
   1. Choose View > Tool Windows > drag-lint
   2. The main drag-lint dockable panel opens (the same panel as from the drag-lint menu)

## Details

This page documents the "View > Tool Windows > drag-lint" menu entry -- the
main drag-lint dockable tool window, reached from RAD Studio's standard
Tool Windows menu instead of the drag-lint menu. It is the same panel as
[drag-lint Panel (dockable)](drag-lint-panel-dockable.md); see that page for
the drag-lint-menu path to it. For the product overview, see the wiki
Home page.

### Running it from the CLI
There is no standalone CLI verb for this (feature map CliVerb:
"(none - in-process)"). It is served in-process by the IDE plugin.

### What it needs
The feature map marks this row's Index column "n/a" and its Mechanism
"in-process". It needs the drag-lint plugin loaded in the IDE.

### Example
Illustrative: choose "View > Tool Windows > drag-lint" to open the main
drag-lint panel.
