# Compile Dependents

Check the units that depend on the one being edited now, instead of waiting for the automatic quiet-period pass (lint-tree tier 3).

Read this when you have changed a unit and want to check the units that depend on it right away. It runs that check now instead of waiting for the automatic quiet-period pass.

## Where to click

* RAD Studio main menu: **drag-lint > Compile Dependents**
