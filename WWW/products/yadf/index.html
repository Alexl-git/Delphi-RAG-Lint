Products · YADF

One formatter. Command line, settings editor and IDE.

YADF (Yet Another Delphi Formatter) reformats .pas, .dpr and .inc source by a rule set you configure: line-length budgeting, structural re-indentation, capitalization and column alignment.

One engine drives the command-line tool, a live-preview settings editor and a Delphi IDE package, from the same settings files. Formatting is idempotent: formatting formatted code changes nothing. A content guard checks every result against its input, and malformed source does not crash it.

01 — How it works

Set it once, format everywhere

1. Tune your styleIn YADFSetup or on the IDE settings page, watching the result change live.
2. Save it as a profileKeep any number of profiles; assign up to two to the IDE shortcuts. The CLI uses the same files.
3. Format anywhereA buffer in the IDE, or a whole project from the command line, with the same result.
