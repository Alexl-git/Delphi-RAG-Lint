Here is a comprehensive report on the refactoring capabilities provided in the IDE for Delphi 11 (Alexandria) and Delphi 12 (Athens).Refactoring in RAD Studio allows you to restructure existing code to improve readability, maintainability, and performance without changing its external behavior. In Delphi 11 and 12, the refactoring engine is accessible via the Refactor main menu, the code editor's right-click context menu, and various keyboard shortcuts.  Core Code Refactoring FeaturesThese are the day-to-day operations used directly within the code editor to clean up logic and manage variables.FeatureWhat It DoesHow to Use ItRenameSafely renames an identifier (class, variable, method) across the entire project, updating all references.Highlight the identifier and press Shift+Ctrl+E, or right-click > Refactor > Rename.Extract MethodTakes a highlighted block of code and moves it into a new, separate method. It automatically passes necessary local variables as parameters.Highlight the code block, press Shift+Ctrl+M, or right-click > Refactor > Extract Method.Declare VariableGenerates a local variable declaration for an undeclared identifier you just typed.Place the cursor on the undeclared variable and click Refactor > Declare Variable.Declare FieldGenerates a field declaration within the current class for an undeclared identifier.Place the cursor on the undeclared field and click Refactor > Declare Field.Extract Resource StringConverts a hardcoded string literal into a resourcestring declaration, useful for localization.Highlight the string, right-click > Refactor > Extract Resource String.Change ParametersAllows you to add, remove, or modify the order of parameters in a method's signature.Place the cursor on a method name, click Refactor > Change Params.Find UnitLocates the unit containing an unresolved identifier and automatically adds it to the uses clause.Click the unresolved identifier, right-click > Refactor > Find Unit.Structural and Object-Oriented RefactoringThese features are geared toward architectural changes and class hierarchy management. Some of these are tightly integrated with Delphi's Modeling/Diagram views.  Extract Interface: Creates a new interface based on the public methods of an existing class.How: Place the cursor inside the class declaration, select Refactor > Extract Interface, and check the methods you want to include.  Extract Superclass: Generates a new base class and allows you to move selected methods and fields from the current class into the new base class.How: Select Refactor > Extract Superclass while inside a class declaration.  Pull Members Up / Push Members Down: Moves methods, properties, or fields up to a parent class or down to derived child classes.  How: Select Refactor > Pull Members Up or Push Members Down and select the target members from the dialog.  Safe Delete: Checks if a method or field is being referenced anywhere else in the project before deleting it, preventing compilation errors.How: Right-click the member and select Refactor > Safe Delete.  Introduce Variable / Field: Evaluates an expression and assigns its result to a newly generated local variable or class field.How: Highlight the expression and select Refactor > Introduce Variable (or Field).  The Refactorings PaneWhen you trigger a complex refactoring action (like renaming a widely used variable or extracting a method), the IDE does not immediately change the code. Instead, it opens the Refactorings Pane at the bottom of the editor.  Preview Changes: The pane displays a tree view of all the files and specific lines of code that will be affected.  Verify: You can review warnings or errors (e.g., if a name conflicts with an existing identifier).Apply: Once satisfied, you click the "Apply Refactoring" button in the pane to commit the changes to your source files.Known Limitations and Community SolutionsWhile the built-in refactoring tools in Delphi 11 and 12 are powerful, developers occasionally experience limitations regarding the newer language features:Inline Variables: The native code analysis engine can sometimes struggle to correctly track or rename inline variables introduced in recent versions of Object Pascal.Community Workarounds: Because of occasional IDE glitches with complex refactoring, many Delphi developers heavily rely on third-party plugins like MMX Code Explorer (which is now free). MMX integrates directly into the IDE and offers a highly robust alternative set of refactoring tools that often handle edge cases better than the native engine.
