## Tasks (failing test first)

1. **Table DDL + migration of fb_columns**: a test creates an index-shaped SQLite file with the CURRENT `fb_columns`
   (copy the DDL from Storage.Schema), runs the ensure-tables routine twice (idempotent), asserts every table/column
   of spec 5 exists and old rows survive with NULL `char_length`.
2. **Row model + SchemaFacts**: insert rows through the writer API, read back via `TSchemaFacts`: char length from the
   column, fallback to the domain, -1 for unknown table / column; `HasSnapshot` false on an empty DB (positive control:
   true after one write); `SnapshotInfo` returns utc + source.
3. **Live reader** (dataset-fed like `FbImport`: the RDB$ queries return TDataSets, tests feed TFDMemTables with the
   same columns): domains (type codes via `DRagLint.FieldRepo.FbTypes`), PK / UNIQUE / FK with ordered columns and
   rules, generators. Live run only when `DL_TEST_FB_CONNECTION` is set (SKIP otherwise; lanes have no credentials);
   it then compares counts with `SELECT count(*)` over the RDB$ tables, never with constants.
4. **DDL reader**: `ddl_basic.sql` -> exact expected rows (domains, constraints, columns, generators);
   `ddl_edge.sql`: SET TERM block skipped, unknown statement counted and listed with its line, quoted identifiers,
   `VARCHAR(n) CHARACTER SET UTF8`, `NUMERIC(p,s)`, `BLOB SUB_TYPE TEXT`. A malformed CREATE TABLE gives an error
   naming file and line, writes nothing (one transaction).
5. **Replace semantics**: a live snapshot followed by a DDL snapshot leaves only `source='ddl'` rows; meta updated.
6. **CLI** (hub commit + runner): `fb-snapshot --ddl tests\fixtures\schema\ddl_basic.sql --db <copy>` exit 0 and
   prints per-table counts; then `sql --query "select count(*) from fb_domains"` equals the expected count; the
   password never appears in output or `fb_snapshot_meta` (assert on a connection string containing `Password=xyz`
   via the live path's meta writer unit test).
7. Encoding guard; lint changed units + lint-all (`--enable magic-literal,multiple-statements-per-line,commented-out-code`);
   featuregen entry + wiki; docs-sync guard (`--ddl` on the `fb-snapshot` help line via the registry entry).
