# v0.82 Implementation Plan -- enclosing_symbol_id attribution + feature-envy + coupling retrofit

> **For agentic workers:** REQUIRED SUB-SKILL: execute with **superpowers:subagent-driven-development** (fresh subagent
> per task, two-stage review each, ledger at `.superpowers/sdd/progress.md`). This plan was written after the v0.82
> brainstorm; the design spec is `docs/superpowers/specs/2026-07-02-v082-enclosing-symbol-attribution-design.md` (read it
> for the grounding file:line anchors). Each task gets a dispatch brief the controller writes from the task text + spec
> anchors; implementers confirm exact AST node shapes with `src\cli\Win64\Debug\dumptree.exe` and measure FP before deciding ON/OFF.

**Goal:** persist an enclosing-method attribution on the reference index (`refs.enclosing_symbol_id`) and consume it to
ship feature-envy, retrofit the ref-based coupling metrics onto exact attribution, and land CK instability, a first-cut
#4, and the two v0.81 Minors.

**Architecture:** additive SQLite column populated per-file in `IndexFile` by innermost impl-range containment (no parser
plumbing, no whole-DB backfill -- DBs are explicitly full-reindexed once after the new exe ships). `TReference` gains an
`EnclosingSymbolId` field; ref-reading store methods populate it; the CK metrics and a new feature-envy rule consume it.

**Tech Stack:** Delphi 13 / RAD Studio 37, FireDAC + SQLite, tree-sitter (Delphi/DFM grammars), the drag-lint CLI.

**Interfaces produced (later tasks consume):**

  contains the ref's `StartLine`; `0` if the ref is not inside any routine body.
- `GetReferencesFromFile(fileId)` now returns refs with `EnclosingSymbolId` populated (and `EndLine`/`EndCol` fixed).

- [ ] **Step 1 (schema):** add `enclosing_symbol_id INTEGER REFERENCES symbols(id) ON DELETE SET NULL` to the `refs`
      CREATE TABLE block in `Schema.pas`; add `CREATE INDEX IF NOT EXISTS idx_refs_enclosing ON refs(enclosing_symbol_id)`;
      bump `SCHEMA_VERSION` -> 13. In `SQLite.pas` add `TryExec('ALTER TABLE refs ADD COLUMN enclosing_symbol_id INTEGER')`
      after the existing ALTER block; extend `FQInsertRef` INSERT column list + params and `UpsertReference` to write it.
- [ ] **Step 2 (model):** add `EnclosingSymbolId: Int64` to the `TReference` record.
- [ ] **Step 3 (attribution):** in `Indexer.pas` `IndexFile`, after the symbols loop (with `IdxToId` built) and while
      inserting refs, compute each ref's innermost enclosing routine from `ParseRes.Symbols` (kinds skMethod/skFunction/
      skProcedure/skConstructor/skDestructor, `ImplStartLine>0`, `ImplStartLine<=Ref.StartLine<=ImplEndLine`, pick the
      LARGEST `ImplStartLine`); map its array index -> DB id via `IdxToId`; set `Ref.EnclosingSymbolId` before
      `UpsertReference`. Refs in no body -> 0.
- [ ] **Step 4 (consumer reads):** populate `EnclosingSymbolId` (NULL-guard `IsNull -> 0`) in `GetReferencesFromFile`,
      `FindReferencesTo`, `FindCallersByName`; ALSO read `end_line`/`end_col` in `GetReferencesFromFile` (pre-existing gap).
- [ ] **Step 5 (fixture, TDD):** add `tests/lint-store/enclosing-attribution/` -- a small unit with a class whose method
      `Bar` calls a free function `Helper` (a `call` ref inside Bar's body) and a nested proc case. Assert attribution via

      into Task 3's retrofit fixture / feature-envy fixture. If a standalone assertion is needed now, add a minimal

- [ ] **Step 6:** build Win64; run all four harnesses -> all green (150/14+/29/33); commit
