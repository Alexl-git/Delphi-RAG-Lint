## Step 0 -- inspect the raw shape first (lesson: never grep output whose shape you did not print)

On the fixture DB print RAW rows: `sql --query "select o.name,o.class_name,o.parent_name,o.obj_kind,o.depth from
dfm_objects o limit 40"` and `select p.object_ordinal,p.parent,p.depth,p.name,p.value_kind,substr(p.value_text,1,60)
from dfm_properties p limit 80`. Record in the hand-back how nested properties (e.g. `DataBinding.FieldName`,
`Properties.OnGetDisplayText`?) and collections (`Columns = <item ...>`) appear, and build the queries on THAT shape.
If collection items / nested properties are not extracted at all, that is an index gap: log it
(`draglint-gaps.log`, class `unsupported`, snippet) and SendMessage main before working around it.
