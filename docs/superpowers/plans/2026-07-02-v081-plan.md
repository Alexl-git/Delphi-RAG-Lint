## Task 1 -- `default-encoding-io` (#9, pure-AST)
File I/O using the DEFAULT (ANSI/locale) encoding where an explicit `TEncoding` should be passed (Win64/Unicode
data-corruption hazard). **Precedent (study first):** `insecure-temp-file` in `src/diagnostics/DRagLint.Diagnostics.DeadCodeChecks.pas`
(`IsFileApiCallee` matches lowercased `entity` text on an `exprCall`) + `path-traversal`'s `PathArgIndex` idiom in
`AstChecks.pas` (resolve callee -> fixed arg index -> `Args:=N.ChildByField('args'); Args.NamedChild(Idx)`; check
`Args.NamedChildCount` for the "no encoding overload" arity). Match set (confirm exact node shapes with
`src\cli\Win64\Debug\dumptree.exe` before coding): `TStringList/TStrings.LoadFromFile`/`SaveToFile` with a single arg
(no `TEncoding`); `TFile.ReadAllText`/`WriteAllText`/`ReadAllLines`/`AppendAllText` in their no-encoding arity;
`TStreamReader`/`TStreamWriter.Create` with no `TEncoding.*` argument; old-style `AssignFile`+`Reset`/`Rewrite`/`Append`
on a text file. Home: `DeadCodeChecks.pas` (sibling of `insecure-temp-file`). Category `platform`; run `src/` FP-sanity
(lint files individually) and **decide ON vs OFF** (bias ON per scout -- it's a real hazard like `nativeint-truncation`;
but `LoadFromFile` without encoding is very common, so if src/ FP is high, ship OFF and document). Wiring: allow-list
guard + help string + DoLint + DoLintAll dispatch + catalog `B('default-encoding-io','platform',<sev>,<title>,<ON|OFF>)`
(+ `DefDisabled` in DoLint & DoLintAll IF OFF). Fixture `tests/lint/default-encoding-io.pas(.expected)` (+ `.config.json`
if OFF): cover a no-encoding call (fires) and an explicit-`TEncoding` call (absent). Severity `warning`.

## Task 2 -- CK `fan-out` (Ce) + `fan-in` (Ca) (store, ClassMetrics)
Two per-class coupling metrics in `src/lint/DRagLint.Lint.ClassMetrics.pas`, both **OFF-by-default**, category `metrics`,
severity `info`, emitted via the existing `Emit(id,msg,CI)` helper (anchors at class decl line). Add two `WantRule`
branches in `TClassMetrics.Run` beside the CK five, thresholds via `ACfg.ThresholdFor(id, default)` mirroring
`high-coupling`.
- **`fan-out` (Ce, efferent):** reuse the existing `ComputeCBO(CI)` value as-is (the codebase's CBO already counts
  efferent `type_use` coupling). Flag when `Ce > threshold` (default 20, mirror `high-coupling`). Message frames it as
  efferent coupling / fan-out. (It intentionally aliases CBO -- ship OFF so it does not double-fire with the ON
  `high-coupling` in default output; opt-in for users who want the fan-in/fan-out pair.)
- **`fan-in` (Ca, afferent -- NEW):** a second whole-project aggregation. In `Run`, after `BuildInventory`, build one
  `TDictionary<Int64,Integer>` of target-class-id -> inbound count: for every file's `GetReferencesFromFile(Fid)` with
  `Kind='type_use'`, resolve `R.NameText` via `ResolveTypeCategory`/the class-name map to the target class id, and
  increment it -- EXCLUDING refs originating from the target's own file/decl-or-method span and self (mirror `ComputeCBO`'s
  exclusions + `GetTransitiveAncestors`). Then flag a class whose Ca > threshold (default OFF; pick a sane default like 20
  and document it needs field tuning). Reuse the `GetRefs` cache and the `Inv`/`ByName` maps already built for the CK suite;
  add NO new store calls beyond `GetAllFileIds`/`GetReferencesFromFile`/`ResolveTypeCategory`/`FindSymbolsByFile`/
  `FindAllChildSymbols`. Determinism: stable iteration.
- Wiring: two `B(...)` catalog rows (`metrics`,`info`,`False`) + BOTH ids in the `DefDisabled` list in the ClassMetrics
  output path (DoLintAll ~CLI 5865; DoLintProject if ClassMetrics is reachable there) -> verify bare `lint-all`/`lint-project`
  produce NO fan-in/fan-out unless config enables. Store fixture `tests/lint-store/ck-fan-coupling/` (mode `lint-all`,
  `config.json` enabling both): a hub class that many others reference (high Ca -> fan-in fires) + a class that references
  many others (high Ce -> fan-out fires) + a low-coupling class (neither). Assert at class-decl lines. src/ FP: run a
  throwaway `src/` index, report Ca/Ce distributions + confirm OFF-suppression end-to-end.
