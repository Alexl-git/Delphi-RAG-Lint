## Tasks (failing test first; RED = test exe before the unit exists / lane engine copy without the verb)

1. **Literal writer**: `PasStringLiteral(s)` -- `''` for a quote, `#13#10` for CRLF, `#nnn` for < 0x20 and > 0x7E,
   pieces <= 200 chars joined by ` +` CRLF; empty string `''`. Tests: quote, CR, LF, tab, `#127`, U+00E9, 450-char
   string (3 pieces, no line > 250), empty.
2. **Record + array emission** for one table: record `T<Table>Row` with Pascal types per `TRepoColKind`
   (string / Integer / SmallInt / Boolean / Byte / string for TEXT); `<Col>IsNull` companion ONLY for columns with a
   NULL in the data; rows in PK order; `array[0..N-1]`; N = 0 emits an empty-array comment + `<TABLE>_ROW_COUNT = 0`
   and no array (Delphi has no empty const array). Expected text compared byte for byte.
3. **Unit wrapper**: `unit <Unit>;` interface/implementation, header comment (source repository base name, per-table
   row counts, "generated by drag-lint repo gen-const -- do not edit"), DocInsight `///` on every public type and
   const; 7-bit ASCII + CRLF; identical bytes on two runs (determinism test).
4. **`--memtable`**: `Fill<Table>(pTable: TFDMemTable)` creates FieldDefs with the FIB$ names/types/sizes of the parent
   design section 4 map (VARCHAR(n) -> ftWideString n, BOOLEAN -> ftBoolean, SMALLINT, INTEGER, TEXT -> ftWideMemo,
   byte -> ftSmallint) and appends every row, NULL columns left NULL.
5. **Compile + round-trip proof** (runner): generate for `tests\fixtures\fieldrepo\golden.txt` (restore into a temp
   repo), compile `ConstProbe.dpr` with dcc32 (rsvars) which uses the generated unit, fills mem tables and prints a
   `#DLREPO`-style dump; the dump must equal `repo backup` of the same repository for the generated tables (DL_META
   excluded). RED: probe source exists before the generator -> compile fails. dcc not found = FAIL, not SKIP.
6. **CLI**: `repo gen-const --repo X --unit uFieldRegistry --output o.pas [--table ...] [--memtable] [--dry-run]`;
   `--dry-run` prints counts and writes nothing; unknown `--table` exit 2; DL_META / DL_EXCEPTIONS /
   DL_LAYOUT_EVENTS / DL_DOMAINS / DL_CONSTRAINTS / DL_CONSTRAINT_COLUMNS / DL_GENERATORS refused in `--table` (exit 2); `--unit` not an identifier exit 2; output path's folder must exist.
7. Lint the GENERATED unit of task 5 with `lint <file>` (must be clean or the generator is fixed); lint changed
   units + lint-all with `--enable magic-literal,multiple-statements-per-line,commented-out-code`; encoding guard;
   featuregen entry + wiki.
