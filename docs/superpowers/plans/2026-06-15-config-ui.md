# drag-lint Visual Configurator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A standalone Win64 VCL app `drag-lint-config.exe` that visually manages the unified `.drag-lint.json` (sections, settings), shows per-folder coverage, previews the resolved plan, and triggers build/drift runs by shelling to `drag-lint.exe`.

**Architecture:** Thin VCL forms over reusable UI-free logic units (`TManifestIO`, `ResolvePlan`, new `ComputeCoverage`, `Drift`, `Reconcile`). Long runs shell out via `TEngineRunner`. Logic is headlessly tested through the CLI's `selftest`; the GUI is compile-verified + manually tested via `docs/TEST-PLAN-CONFIG.md`.

**Tech Stack:** Delphi 13 VCL (Win64), `System.JSON`, `Vcl.ComCtrls` (TPageControl/TTreeView/TListView), `CreateProcess` pipes. Spec: `docs/superpowers/specs/2026-06-15-config-ui-design.md`. Branch `feat/index-manifest`.
**Build engine:** `cmd.exe /c "call \"C:\Program Files (x86)\Embarcadero\Studio\37.0\bin\rsvars.bat\" && msbuild /t:Build /p:Config=Debug /p:Platform=Win64 <proj>"`. Engine exe at `src\cli\Win64\Debug\drag-lint.exe`; copy to `third_party\dll-win64\drag-lint.exe` after engine changes.
**Conventions:** `.pas`/`.dfm` 7-bit ASCII + CRLF; DocInsight on public surface; register new units in their project's `.dpr`+`.dproj`; `try-finally` for owned objects.

- [ ] **Step 1: Public API** in `DRagLint.Index.Coverage.pas`:
```pascal
type
  TCoverageKind = (ckIndexed, ckOverlap, ckExcluded, ckLibrary, ckUnassigned);
  TCoverageItem = record
    Folder: string; Kind: TCoverageKind; Detail: string;
  end;
  /// <summary>Classify each immediate child folder of ARoot by how AManifest
  /// covers it. Read-only (filesystem + manifest). AResolver supplies library
  /// roots.</summary>
  function ComputeCoverage(const AManifest: TIndexManifest; const ARoot: string;
    AResolver: TProjectResolver): TArray<TCoverageItem>;
function CoverageKindStr(K: TCoverageKind): string;
```
