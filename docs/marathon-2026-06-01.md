## Phase 1 -- F7 open-in-IDE (live jump-to-source)
- graph: `LocateSymbol` resolves by `symbols.id` (DbId), not qname (overload-safe,
  Q1); send `<file><TAB><line><TAB><col>` (Q3); map `.dfm`->`.pas` (Q5).
- core: `TOpenSourceServer` -- named-pipe server `\\.\pipe\drag-lint-open-source`,
  overlapped I/O so the listener thread unblocks cleanly on package unload
  (avoids the v0.40 teardown AVs). Marshal to main thread; `OpenFile` +
  `GotoLine` + column. Register/teardown in the Wizard.
- verify here: BPL builds; OpenSource client unit tests stay green.
- verify in IDE: install BPL, run viewer, click a method -> editor jumps.

## Phase 2 -- Uses/const resolver (idea #1)
- core: `drag-lint resolve-uses --name FOO [--in <file.pas>] [--json]` -- finds
  every symbol named FOO across the index (or restricted to a kind), returns the
  defining unit(s), **ranked**: same-project > library; units not already in the
  caller's `uses` first; kind/type affinity as a tiebreak. Honest about being a
  heuristic where value-type isn't indexed.
- LSP: code-action "Add unit X to uses" on an unresolved identifier.
- verify here: headless tests over the self/ORM3 index.

- verify here: search backend query tests.
- verify in IDE: panel docks, search returns, double-click navigates.
