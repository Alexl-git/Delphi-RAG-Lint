  every symbol named FOO across the index (or restricted to a kind), returns the

  heuristic where value-type isn't indexed.

## Phase 6 -- Syntax / compiler errors  [INVESTIGATED]
Finding: the diagnostics PIPELINE is complete and intact --
`TLspCompletion.BuildDiagnostics` -> `textDocument/publishDiagnostics` ->
plugin `DragLint.Plugin.DiagnosticCache` -> `EditViewNotifier` paints per-line
markers. It currently surfaces **lint rules + imported compiler_findings**
(from `import-log`) + two AST checks (unbalanced begin/end, undeclared ident).
It does **not** surface live **syntax/parse errors**.
Gap + fix (clean, contained): add `TAstChecker.CheckSyntaxErrors` that parses
the file and walks the tree for nodes where `IsError`/`IsMissing` is true
(`third_party/delphi-tree-sitter/TreeSitter.pas` already exposes these),
emitting a `TLintFinding` at each error node's line/col. It then flows through
the existing publishDiagnostics -> marker path for free. Compose it into
`TAstChecker.Check` alongside the existing sub-checks.
