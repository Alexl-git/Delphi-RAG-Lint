# Quick Help

One line per feature, grouped as on [Features](Features), with the short help and the words people search for. Every line links the feature's own page; this page is generated from the feature registry and never edited by hand.

## Indexing

* **Auto-Document Whole Project** -- Writes DocInsight documentation into every public declaration a project owns. Read this when a whole project needs documentation coverage instead of symbol-by-symbol work. It writes DocInsight comments into every public declaration the project owns, as a batch of reindex, document and reindex. [More](Auto-Document-Whole-Project)
* **Include-file indexing and IF evaluation** -- Include files are indexed under the active build, value defines and IF expressions are evaluated, and an undecidable IF is reported as a pp-unresolved-if hint. Read this when units pull code from .inc files or choose branches with IF directives. The indexer follows includes, evaluates value defines, Declared() and true constants, and says so when it cannot decide a branch. [More](inc-indexing)
* **Index a project against its active build config** -- Parses a project index against the project's active build config (the .dproj Config marker or delphilsp.json) instead of a fixed Release, with an override flag. Read this when a project index must show the code your IDE compiles, for example IFDEF DEBUG branches, or when you want to index a specific build such as Release for a ship view. The index follows the project's active configuration and records it, so a config switch re-parses exactly that database. [More](index-build-config)
* **migrate-dbs** -- Moves project index databases into each project's own D-RAG folder, matching the current index layout. Read this after an index layout change, or when index databases are stranded in an old shared folder. It moves each project index into that project own _D-RAG folder; without --apply it only reports what it would move. [More](migrate-dbs)
* **pp-profile** -- Diagnostic that prints the resolved preprocessor define profile for a project, one symbol per line. Read this when you need to know which compiler defines are active for a project, platform and configuration, before trusting a preprocess or index result. It prints the resolved define set, one symbol per line, exactly as the indexer sees it. [More](pp-profile)
* **purge-locals** -- A size escape hatch for an index database that has grown too large: it drops local-variable and parameter symbols and runs VACUUM to reclaim space. Read this when an index database has grown larger than you want and you do not need per-local symbol lookups right now. It drops local-variable and parameter symbols and runs VACUUM; the call graph is unchanged and the symbols return on the next index. [More](purge-locals)
* **Rebuild Index for This Project** -- Walks a project's .dproj compile closure and (re)builds its index. Read this after adding or moving units, or when hover, Find Usages or lint results feel stale. It walks the project .dproj compile closure and rebuilds the index for that project. [More](Rebuild-Index-for-This-Project)
* **register-project** -- Add a new project to the manifest so index --all and the IDE can see it. Read this when a new project is not yet known to drag-lint. It adds the .dproj to the manifest so index --all and the IDE can see it; without --apply it is a dry run. [More](Features)
* **schema** -- Prints the live schema of an index database: schemaversion, every table and column, and row counts. Read this when you need to know exactly what an index database contains before you query it: schema prints the schema version, every table and column, and row counts, read-only. [More](schema)
* **Show Resolved DBs (debug)** -- Prints which database(s) drag-lint would actually use for a given project, file, or platform, without running a real query. Read this when a query seems to answer from the wrong index: it prints which database(s) drag-lint would use for a project, a file or a platform, without running a real query. [More](Show-Resolved-DBs-debug)

## Search and navigation

* **Class Surface** -- Shows the public surface of a class: its members and signatures, without the method bodies. Read this when you want to know what a class exposes without reading the whole unit. Class Surface shows its members and signatures, without the method bodies. [More](Class-Surface)
* **Compiler Hints** -- Uses query hints to surface compiler hint/warning findings that have been imported into the index, filtered by code or severity. Read this when you want to review compiler hints and warnings without running a build. Compiler Hints lists the ones already imported into the index, filterable by hint code or severity. [More](Compiler-Hints)
* **context** -- Returns a compact context bundle for a symbol -- its doc comment, class surface (signatures), the target's own body, and a capped list of callers. Read this before editing or explaining a symbol. context returns a compact bundle, its doc comment, class surface, own body and a capped list of callers, so you read a fraction of what a whole-file read costs. [More](context)
* **Find Undocumented (public)** -- Uses query find to list indexed symbols filtered by documentation state, kind, or visibility. Also under drag-lint > Code Quality in the IDE. [More](Find-Undocumented-public)

* **Find Usages** -- Lists references to the symbol represented by a Structure-tree node. Read this when you are browsing the Structure form and want the usages of a symbol without first opening it in the editor. * **find-callees** -- Lists the resolved outgoing calls of one routine, plus the library-bound ones. Read this when you want to know what a routine actually calls, resolved through the index rather than by reading its source. find-callees --qname Foo.Bar lists its outgoing calls; add --json for machine-readable output. [More](find-callees)
* **find-unit** -- Finds which indexed unit declares a symbol, and adds that unit to a file's uses clause. Read this when a symbol is undeclared and you need the unit to add to uses. find-unit --name X --in file looks the declaring unit up in the index and can add it to the file (--apply, with a backup unless --no-backup). Without --apply it is a dry run: it prints the uses-clause edit, exits 0 and writes nothing (--json prints the edit set and never writes). * **helpers-of** -- Lists record/class helper edges targeting a given type, anywhere in the index. [More](helpers-of)
* **Hover at Cursor** -- Shows a hover card for the symbol under the editor caret: signature, documentation, and callers. * **Symbol Search** -- Searches symbols by name across the indexed projects. Read this when you know or can guess a symbol name but not its file: Symbol Search finds types, methods and fields by name across the indexed projects, bound to Ctrl+Alt+T. [More](Symbol-Search)
* **Symbol Slice** -- Shows the slice of code relevant to one symbol: its declaration, body, and immediate context. Read this when you want only the code that matters for one symbol instead of the whole file: it shows the symbol declaration, body and immediate context. [More](Symbol-Slice)
